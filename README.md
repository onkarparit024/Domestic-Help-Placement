# Domestic Help Placement System

## About the Project
This is a BCA major project that helps users find domestic helpers for household services.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Features
- Home page
- Domestic services listing
- User registration and login
- Worker listing API
- MySQL database connectivity

## Project Structure
- `frontend` - Website files
- `backend` - Server and API files
- `docs` - Project documentation

## How to Run
1. Install Node.js and MySQL.
2. Configure database credentials in the backend `.env` file.
3. Open the backend folder in the terminal.
4. Run `npm install`.
5. Run `node server.js`.
6. Open the frontend `index.html` file in your browser.
