# Domestic Help Placement Management System

## Project Objective

Build a practical management system for a domestic help placement agency.

The system will replace scattered registers, spreadsheets and informal communication with one searchable and controlled application.

## User Roles

1. Admin/Owner
2. Staff/Operator
3. Customer/Beneficiary/Client

## Main Modules

- Authentication & Roles
- Worker Management
- Client Management
- Skills Management
- Availability Management
- Worker-Client Matching
- Verification
- Placement Management
- Payment / Receipt
- Contract Management
- Replacement Request
- Search & History
- Reports & Dashboard
- Notifications / Status Tracking
- Settings & Audit

## Main Workflow

Worker Profile
→ Client Requirement
→ Matching
→ Verification
→ Placement
→ Fee / Contract
→ Replacement
