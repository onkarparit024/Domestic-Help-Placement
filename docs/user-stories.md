# User Stories

## 1. Admin / Owner

### Authentication
- As an Admin, I want to log in securely so that I can access the management system.

### User and Role Management
- As an Admin, I want to manage users and their roles so that access can be controlled.

### Worker Management
- As an Admin, I want to create, view, update and manage worker records.

### Client Management
- As an Admin, I want to create, view, update and manage client records.

### Placement Management
- As an Admin, I want to view and manage placement records.

### Reports
- As an Admin, I want to view reports and dashboard information.

### Security
- As an Admin, I want sensitive operations to be restricted to authorized users.


## 2. Staff / Operator

### Authentication
- As a Staff member, I want to log in so that I can perform my assigned work.

### Worker Management
- As a Staff member, I want to create worker profiles.
- As a Staff member, I want to search and filter workers.
- As a Staff member, I want to view worker details and history.

### Client Management
- As a Staff member, I want to create client records.
- As a Staff member, I want to record client requirements.
- As a Staff member, I want to search and filter client records.

### Matching
- As a Staff member, I want to match workers with client requirements.

### Verification
- As a Staff member, I want to complete worker verification before placement.

### Placement
- As a Staff member, I want to create and manage placements.
- As a Staff member, I want to update placement status.

### Payment and Contract
- As a Staff member, I want to record placement fees and payments.
- As a Staff member, I want to manage contract information.

### Replacement
- As a Staff member, I want to manage replacement requests when required.


## 3. Customer / Client

### Authentication
- As a Client, I want to log in securely so that I can access my information.

### Requirements
- As a Client, I want to provide my domestic-help requirements.

### Worker Matching
- As a Client, I want to view relevant worker information.

### Placement Tracking
- As a Client, I want to track the status of my placement.

### Contract and Payment
- As a Client, I want to view relevant contract and payment information.


## 4. General System Requirements

- Users should only access features allowed for their role.
- Important records should have status and history.
- Important forms should validate required information.
- Search and filtering should work correctly.
- Important financial and status changes should be traceable.
